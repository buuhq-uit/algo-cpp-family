# LC 560 – Subarray Sum Equals K
# Đếm số đoạn con có tổng bằng K

---

## 📝 PROBLEM STATEMENT (ENGLISH)

Given an integer array `nums` and an integer `k`,  
return the total number of continuous subarrays whose sum equals to `k`.

A subarray is a contiguous non-empty sequence of elements within an array.

---

## 📝 ĐỀ BÀI (TIẾNG VIỆT)

Cho một mảng số nguyên `nums` và một số nguyên `k`.

Hãy đếm số lượng đoạn con liên tiếp (subarray) sao cho tổng các phần tử trong đoạn đó bằng `k`.

Lưu ý:
- Đoạn con phải liên tiếp.
- Mảng có thể chứa số âm.

---

## 📌 Ví dụ

Input:
nums = [1,1,1], k = 2  

Output:
2  

Giải thích:
Có 2 đoạn:
- [1,1] (vị trí 0–1)
- [1,1] (vị trí 1–2)

---

# 🧠 TƯ DUY GIẢI (IDEA)

## 🚨 Nhận diện pattern

Dấu hiệu:
- Đếm số đoạn con
- Tổng bằng k
- Có thể có số âm

→ Nghĩ ngay đến:
✅ Prefix Sum + HashMap

---

## 🔎 Phân tích toán học

Gọi:

prefix[i] = tổng từ 0 → i

Ta có:

sum(l → r) = prefix[r] − prefix[l−1]

Muốn sum(l → r) = k  
⇔ prefix[r] − prefix[l−1] = k  
⇔ prefix[l−1] = prefix[r] − k

→ Với mỗi vị trí r:
Chỉ cần biết có bao nhiêu prefix trước đó bằng (prefix[r] − k)

→ Dùng HashMap lưu tần suất prefix.

---

# ⚙️ SOLUTION (C++)

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int,int> freq;
        freq[0] = 1;  // prefix sum = 0 xuất hiện 1 lần

        int prefix = 0;
        int count = 0;

        for(int num : nums) {
            prefix += num;

            // Nếu tồn tại prefix trước đó = prefix - k
            if(freq.count(prefix - k)) {
                count += freq[prefix - k];
            }

            freq[prefix]++;
        }

        return count;
    }
};
```
